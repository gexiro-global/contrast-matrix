# Contributing

Thank you for contributing to contrast-matrix.

1. Fork the repository and create a focused branch.
2. Install the development dependencies with `python -m pip install -e '.[dev]'`.
3. Add tests for behavioral changes and run `pytest -q`.
4. Open a pull request describing the problem and the solution.

Keep changes small, deterministic, offline-capable, and compatible with Python 3.9 through 3.13.
By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
